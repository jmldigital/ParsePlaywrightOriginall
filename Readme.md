# 🚀 Async Auto Parts Parser (Playwright)

Асинхронный парсер автозапчастей с поддержкой:
- 🔍 поиска цен
- 🏷 поиска названий деталей
- 🤖 обхода капчи (2Captcha)
- 🌐 прокси (rucaptcha proxy rotation) - не используем
- ⚡ конкурентной обработки (async + workers)
- 📊 постобработки цен

---

## ⚙️ Основные возможности

- Асинхронный парсинг через Playwright
- Параллельная обработка (worker pool)
- Общая авторизация (cookie reuse)
- Автоматический re-login
- Обход капчи через 2Captcha
- Переключение на прокси при rate limit (сейчс отключил)
- Поддержка нескольких источников:
  - stparts
  - avtoformula
  - adeo
  - emex
- Промежуточное сохранение данных
- Финальная корректировка цен

---

## 🧪 Режимы работы

В системе есть 3 режима, но одновременно активен только один:

| Режим | Переменная |
|------|--------|
| 🏷 Названия | ENABLE_NAME_PARSING=True |
| 💰 Цены | ENABLE_PRICE_PARSING=True |
| ⚖️ Вес | ENABLE_WEIGHT_PARSING=True | (вес убрал в отдельный прасре, по этмоу здесь не используем)

## 💰 Логика корректировки цен

Алгоритм:
1. Берём свою цену
2. Собираем конкурентов (1–4 дня доставки)
3. Если есть дешевле → снижаем (помечаем в итоговом айле красным цветом)
4. Иначе — оставляем (зеленый цвет)
